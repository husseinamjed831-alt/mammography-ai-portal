# Mammography AI

نظام يساعد بفحص سرطان الثدي من صور الماموغرام: الطبيب يرفع الصورة، الموديل يحللها، يطلع تقرير PDF،
والمريضة تشوف تقاريرها ببوابة خاصة. الواجهة مبنية بـ WebGL (Three.js) مع تنقلات متحركة (GSAP).

> أداة مساعدة للبحث ودعم القرار — مو أداة تشخيص معتمدة. التشخيص النهائي للطبيب المختص.

## هيكل المشروع

| الملف | شنو يسوي |
|---|---|
| `server.py` | الخادم الجديد (FastAPI): الـ API + يقدّم واجهة WebGL |
| `web/index.html` + `web/js/app.js` | واجهة الطبيب: مقدمة ← بيانات المريضة ← مسح ← نتيجة |
| `web/portal.html` + `web/js/portal.js` | بوابة المريضة: تسجيل دخول ← التقارير |
| `web/js/scene.js` | مشهد WebGL: كرة جسيمات (70 ألف نقطة) تتغير حسب حالة التحليل |
| `web/js/ui.js` | التنقل بين الصفحات، الرسائل، الاتصال بالـ API |
| `web/css/style.css` | التصميم |
| `model.py` | تحميل الموديل والتنبؤ (مشترك بين النسختين) |
| `report_pdf.py` | إنشاء تقرير الـ PDF |
| `database.py` | قاعدة البيانات SQLite (المريضات + التقارير) |
| `mammo_xgb.pkl` | الموديل الحالي (EfficientNetB0 + XGBoost) |
| `training/train_mammo.py` | تدريب موديل أقوى على GPU (Kaggle/Colab) |
| `app.py` / `portal.py` | النسخة القديمة بـ Streamlit — بعدها تشتغل |
| `Dockerfile` | للنشر على Hugging Face أو أي سيرفر |

### الموديل
`model.py` يختار تلقائياً:
1. `mammo_model.keras` إذا موجود ← الموديل الجديد (من `training/`)، مع العتبة من `mammo_model.json`
2. وإلا `mammo_xgb.pkl` ← الموديل القديم

يعني تدرب الموديل الجديد، تحطه جنب `server.py`، وكل شي يشتغل بدون تغيير كود.

## التشغيل على جهازك

```bash
pip install -r requirements.txt
uvicorn server:app --port 7860
```
- واجهة الطبيب: http://localhost:7860
- بوابة المريضة: http://localhost:7860/portal

النسخة القديمة بعدها تشتغل: `streamlit run app.py`

## الإعدادات (متغيرات البيئة)

| المتغير | شنو يسوي |
|---|---|
| `DOCTOR_PASSWORD` | كلمة سر واجهة الطبيب. **لازم تضبطها بالنشر**، بدونها أي أحد يكدر يحلل ويسجل مرضى |
| `MAMMO_SECRET` | مفتاح توقيع الجلسات (نص عشوائي طويل). بدونه الجلسات تنمسح كل ما يعيد السيرفر تشغيله |
| `MAMMO_DATA_DIR` | وين تنحفظ قاعدة البيانات والتقارير (الافتراضي: المجلد الحالي) |

## النشر حتى يبقى شغال (Hugging Face Spaces)

Hugging Face Spaces = استضافة مجانية تشغّل المشروع على الإنترنت ويصير إله رابط ثابت تفتحه من أي مكان.

1. سوّي حساب على https://huggingface.co
2. **New Space** ← اختار **Docker** ← **Blank**
3. ارفع ملفات المشروع للـ Space (أو اربطه بهذا المستودع من GitHub)
4. **Settings ← Variables and secrets** ← أضف كـ *Secrets*:
   - `DOCTOR_PASSWORD` = كلمة سر قوية
   - `MAMMO_SECRET` = نص عشوائي طويل
5. انتظر البناء (~5-10 دقايق) والرابط يصير جاهز

**ملاحظات مهمة:**
- المساحة المجانية **تنام** إذا ماكو أحد فاتحها 48 ساعة، وتصحى لحالها أول ما أحد يفتح الرابط (تاخذ دقيقة).
- القرص بالمساحة المجانية **مؤقت**: قاعدة البيانات والتقارير تنمسح عند إعادة التشغيل.
  حتى تنحفظ: **Settings ← Persistent storage** (مدفوع، تقريباً 5$ بالشهر) والمشروع يستخدم `/data` تلقائياً.
- إذا الموديل الجديد `mammo_model.keras` أكبر من 10MB، ارفعه بـ Git LFS: `git lfs track "*.keras"`.
- قبل استخدامه مع بيانات مريضات حقيقية، تأكد من قوانين حماية البيانات الطبية ببلدك.
